How the functions call each other

Each function builds on the one before it. Only is_taken() gives a yes or no; the others return a number between 0 and 1.

coverage(spot, car)One spot, one car. Returns a fraction.uses shapely: Polygon, box, intersection
iou(spot, car)Same inputs, stricter score. Kept for comparison in Block 4.uses shapely: intersection, union
best_coverage(spot, cars)One spot, many cars. Calls coverage once per car, keeps the biggest.calls coverage()
is_taken(spot, cars)Compares the best coverage to the threshold (0.5). Returns True or False.calls best_coverage()
